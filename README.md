# MIDI Looper v1

MIDI-лупер на ESP32. Записывает MIDI-события (ноты, CC) со входа, зацикливает и воспроизводит на выход. Темп и такт берёт из внешнего MIDI-клока. Управляется педалью, четырьмя кнопками у экрана, энкодером и по BLE.

## 1. Железо

| Узел | Пины |
|---|---|
| MIDI IN / OUT (UART2, 31250 бод) | RX 16, TX 17 |
| Педаль лупера | 2 |
| LED (PWM) | 1 |
| Энкодер CLK / DT / SW | 5 / 4 / 3 |
| OLED SSD1315 (I2C, 0x3C) | SDA 9, SCL 8 |
| Кнопки у экрана (сверху вниз) | 13, 12, 11, 10 |

## 2. Управление

### Педаль (пин 2)
- **Короткое нажатие** переключает режимы по кругу: `IDLE → REC → PLAY → OVERDUB → PLAY → …`
- Старт и стоп записи ставятся в очередь и срабатывают **в начале ближайшего такта**. Пока команда ждёт, LED мигает.
- **Удержание > 1,5 с** — полный Reset.
- Педаль отключается флагом `PEDAL_ENABLED 0`.

### Кнопки у экрана

| Кнопка | Действие |
|---|---|
| 1 (верх, пин 13) | **Reset** — остановка и очистка лупа |
| 2 (пин 12) | **Пресеты.** Короткое нажатие — выбор слота для загрузки. Удержание 2 с — выбор слота для сохранения. |
| 3 (пин 11) | **Undo** — удалить последний слой овердаба |
| 4 (низ, пин 10) | **Menu** — открыть меню / отмена редактирования / выход из подменю / выход из меню |

### Энкодер
- В обычном режиме **ничего не делает**.
- В меню и при выборе слота вращение перемещает курсор или меняет значение, **клик подтверждает**.
- Любой режим закрывается сам через 12 с без действий.

### Выбор слота пресета
Слот выбирается энкодером, клик по энкодеру подтверждает, повторное нажатие кнопки 2 отменяет.
- Занятые слоты отмечены `*`.
- При сохранении в занятый слот на экране показывается `SAVE: overwrite!`.

## 3. Экран

```
PLAYING          2 bars      ← состояние, длина лупа в тактах
120 BPM          4364ms      ← темп (из MIDI-клока), длина в мс
[▮▮▮▮][▮▮  ][    ][    ]    ← прогресс: 4 сегмента = 4 доли такта
Grid:Q16 Str:100%
Quantize:start+end
Preset: 2 [x]                ← последний выбранный слот ([x] — занят)
(сообщение / подсказка)
```

- Во время записи шапка показывает число уже полностью записанных тактов и текущее время записи.
- Если MIDI-клока нет, действует внутренний счёт ≈110 BPM (545 мс на долю).

## 4. Меню

Вход — кнопка 4. Энкодер двигает по списку, клик входит в пункт или выполняет действие.

| Пункт | Описание |
|---|---|
| **Grid** | Сетка квантизации: OFF, Q32, Q16, Q8, Q4 (Q4 — по долям) |
| **Strength** | Сила притяжения к сетке, 0–100%, шаг 5 |
| **Target** | Что квантизируется: `starts` — начала нот (note-on) и CC, `ends` — концы нот (note-off), `start+end` — и то и другое |
| **Apply quantize** | Применить текущие Grid, Strength и Target к уже записанному лупу |
| **Channels** | Подменю фильтра MIDI-каналов записи (см. ниже). Справа показано число активных каналов, например `14/16` |
| **Half loop** | Сократить луп вдвое, события второй половины отбрасываются |
| **Double loop** | Удвоить луп, события дублируются |
| **Octave down / up** | Транспонировать луп на −12 / +12 полутонов |
| **Delete preset** | Выбрать слот и удалить пресет |

Квантизация работает в двух режимах: **на лету** при записи (если Grid не OFF) и **постфактум** через Apply quantize. Слишком короткие после квантизации ноты автоматически удлиняются до минимальной длины.

### Подменю Channels
Сетка 2×8 с каналами 1–16 и двумя кнопками внизу.

| Элемент | Значение |
|---|---|
| Залитая клетка | канал **записывается** |
| Цифра без заливки | канал **игнорируется** |
| Рамка | текущая позиция курсора |
| `ALL ON` / `ALL OFF` | включить / выключить все каналы |

- **Энкодер** двигает курсор, **клик** переключает канал.
- **Кнопка Menu** — возврат в основной список.
- Настройка **сохраняется** во флеш (`/chmask.bin`) и переживает перезагрузку.
- Фильтр действует только на **запись**. Входящий MIDI принимается со всех каналов, а при воспроизведении события уходят на тех каналах, на которых были записаны.
- **По умолчанию** каналы 11 и 12 выключены (как в прежних версиях), остальные включены.
- Если выключить канал, пока на нём звучит нота, её Note Off всё равно будет записан, чтобы в лупе не осталось залипшей ноты.

## 5. Что записывается
- **Записываются:** Note On / Note Off и Control Change.
- **Не записываются:** Pitch Bend, Aftertouch, Program Change, SysEx.
- **Режим thru выключен:** входящие события не пересылаются на выход, на выход идёт только воспроизведение лупа.
- **Лимиты:** до 5000 событий, длина лупа не более 65 с.

## 6. Работа лупера
- **Слои.** Каждый овердаб пишется как новый слой. Undo снимает последний слой.
- **CC-автоматизация.** Если во время воспроизведения вы сами двигаете CC, записанные значения этого CC на 1,2 с уступают вашему управлению. В овердабе приоритет у более нового слоя.
- **Пресеты:** 5 слотов во флеш-памяти (LittleFS, `/presetN.bin`).
  - Сохранять можно только при PLAY или OVERDUB.
  - Загрузка в играющий луп происходит **в конце текущего круга**. Если лупа нет, пресет загружается сразу.

## 7. LED
LED пульсирует в такт: на первой доле такта ярче, на остальных слабее. В REC и OVERDUB пульс инвертируется. Быстрое мигание означает, что команда старт или стоп ждёт начала такта. Очень быстрое мигание означает, что педаль удерживается до сброса.

## 8. BLE
Устройство: `MIDI-Looper`. Команды пишутся в характеристику (write), ответы приходят уведомлениями (notify).

| Команда | Действие |
|---|---|
| `/rec`, `/stop`, `/overdub`, `/play` | Запись и воспроизведение |
| `/reset`, `/undo` | Сброс, отмена слоя |
| `/half`, `/double` | Длина лупа ×½ и ×2 |
| `/transpose N` | Транспонировать на N полутонов |
| `/save N`, `/load N`, `/delp N`, `/getpresets` | Пресеты (слот 1–5) |
| `/qgrid 0..4`, `/qstrength 0..100`, `/qtarget 0..2` | Параметры квантизации (target: 0 — start, 1 — end, 2 — both) |
| `/getquant`, `/qapply` | Запрос параметров квантизации, применение квантизации |
| `/chmask N` | Маска каналов записи (бит 0 = канал 1 … бит 15 = канал 16), N = 0..65535 |
| `/getch` | Запросить текущую маску |

Основные уведомления:
- **Состояние:** `/state`, `/pos`, `/rec_pos`, `/beatinfo`.
- **События для визуализации:** `/noteon`, `/noteoff`, `/cc` и их `/rec_*` варианты.
- **Статусы:** `/presets`, `/quant`, `/chmask`, `*_ok`, `*_err`.
