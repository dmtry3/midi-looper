# MIDI Looper

MIDI-лупер на ESP32. Записывает MIDI-события (ноты, CC) со входа, зацикливает и воспроизводит на выход (DIN и, опционально, USB). Темп и такт берёт из внешнего MIDI-клока. Управляется педалью, четырьмя кнопками у экрана, энкодером и по BLE.

Версия прошивки: **v2.2**.

Пресеты, сохранённые прошивкой v1 (длина лупа в миллисекундах), этой версией не читаются: при загрузке будет ошибка `load_err`.

## 1. Железо

| Узел | Пины |
|---|---|
| MIDI IN / OUT (UART2, 31250 бод) | RX 16, TX 17 |
| USB MIDI (опционально, нативный USB ESP32-S2/S3) | USB-порт платы |
| Педаль лупера | 2 |
| LED (PWM) | 1 |
| Энкодер CLK / DT / SW | 5 / 4 / 3 |
| OLED SSD1315 (I2C, 0x3C) | SDA 9, SCL 8 |
| Кнопки у экрана (сверху вниз) | 13, 12, 11, 10 |

## 2. Настройки прошивки (`#define` в начале файла)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `USB_MIDI_ENABLED` | `1` | USB MIDI (только ESP32-S2/S3). `0` — отключить |
| `PEDAL_ENABLED` | `1` | Реакция на педаль. `0` — полностью отключить |
| `OLED_ENABLED` | `1` | Экран |
| `ECHO_GUARD_MS` | `40` | Окно защиты от эха (мс), см. раздел 8 |
| `DEFAULT_CH_MASK` | `0xFFFF` | Каналы записи по умолчанию (все 16) |
| `VIZ_NOTE_LO` / `VIZ_NOTE_HI` | `24` / `103` | Диапазон нот на индикации |
| `VIZ_MAX_H` | `6` | Максимальная высота полоски индикации (пиксели) |

## 3. Управление

### Педаль (пин 2)
- **Нажатие** переключает режимы по кругу: `IDLE → REC → PLAY → OVERDUB → PLAY → …`
- Старт и стоп записи ставятся в очередь и срабатывают **в начале ближайшего такта**. Пока команда ждёт, LED «дышит». Поэтому длина лупа всегда равна целому числу тактов.
- Вход в овердаб и выход из него срабатывают **сразу**, без ожидания такта.
- Действие срабатывает при **нажатии**. Сброса по долгому удержанию нет, для сброса есть кнопка Reset.

### Кнопки у экрана

| Кнопка | Действие |
|---|---|
| 1 (верх, пин 13) | **Reset**: остановка и очистка лупа, отмена ожидающих старта/стопа записи и загрузки пресета |
| 2 (пин 12) | **Пресеты.** Короткое нажатие — выбор слота для загрузки. Удержание 2 с — выбор слота для сохранения. |
| 3 (пин 11) | **Undo**: удалить последний слой овердаба (во время овердаба удаляет текущий слой и возвращает в PLAY) |
| 4 (низ, пин 10) | **Menu**: открыть меню / отмена редактирования / выход из подменю / выход из меню |

### Энкодер
- В обычном режиме **ничего не делает**.
- В меню и при выборе слота вращение перемещает курсор или меняет значение, **клик подтверждает**.
- Любой режим закрывается сам через 12 с без действий.

### Выбор слота пресета
Слот выбирается энкодером, клик по энкодеру подтверждает, короткое нажатие кнопки 2 отменяет (и при загрузке, и при сохранении).
- Занятые слоты отмечены `*`.
- При сохранении в занятый слот показывается `SAVE: overwrite!`.
- Сохранять можно только при PLAY или OVERDUB.

## 4. Экран

```
PLAYING          2 bars      ← состояние, длина лупа в тактах
120 BPM          4.00s       ← темп (из MIDI-клока), длина в секундах
[▮▮▮▮▮▮▮▮▮▮][▮▮▮▮▯▯▯▯▯▯]     ← прогресс по тактам (сегмент = такт)
Grid:Q16 Str:100%
Quantize:start+end
Preset: 2 [x]                ← последний выбранный слот ([x] — занят)
▁▃█▂   ▅  ▁▃▆                ← индикация нот (самая нижняя строка)
```

- **Шапка.** Первая строка — состояние и длина лупа в тактах, вторая — BPM и длина в секундах. Во время записи показываются число уже полностью записанных тактов и текущее время записи.
- **Прогресс-бар по тактам.** Сегменты растянуты на всю ширину экрана.
  - **IDLE**: один прямоугольник, он плавно заполняется в течение текущего такта (как метроном).
  - **RECORDING**: бар растёт. Записанные такты залиты, текущий заполняется, на каждом новом такте добавляется сегмент.
  - **PLAYING / OVERDUB**: столько сегментов, сколько тактов в лупе. Заполнение идёт по позиции воспроизведения.
  - Максимум отображается 40 сегментов.
- **Строка `Preset: …`** временно подменяется сообщениями: `Saved 2`, `Reset`, `Load 3 on beat 1`, `Load 3 at loop end`, `Hold 2s = SAVE...`, `Load N pending...` и т. п.
- В меню, подменю Channels и выборе слота строки `Grid`, `Quantize` и `Preset` заменяются соответствующим экраном.
- Если MIDI-клока нет, через 1,2 с включается внутренний клок (см. раздел 8).
- Экран рисуется в отдельной задаче на втором ядре и не тормозит MIDI.

## 5. Меню

Вход — кнопка 4. Энкодер двигает по списку (видно 3 строки), клик входит в пункт или выполняет действие.

| Пункт | Описание |
|---|---|
| **Grid** | Сетка квантизации: OFF, Q32, Q16, Q8, Q4 (Q4 — по долям) |
| **Strength** | Сила притяжения к сетке, 0–100%, шаг 5 |
| **Target** | Что квантизируется: `starts` — начала нот (note-on), `ends` — концы нот (note-off), `start+end` — и то и другое. CC не квантизируются никогда, чтобы плавные свипы не превращались в ступеньки |
| **Apply quantize** | Применить текущие Grid, Strength и Target к уже записанному лупу. Не работает при Grid = OFF или Strength = 0% |
| **Channels** | Подменю фильтра MIDI-каналов записи (см. ниже). Справа показано число активных каналов, например `14/16` |
| **Transpose** | Транспонирование лупа: энкодером выбирается сдвиг **−12…+12 полутонов** (`>+5 st<`), клик применяет. Значение 0 ничего не меняет. Ноты, вышедшие за 0…127, прижимаются к краю диапазона |
| **Half loop** | Сократить луп вдвое, события второй половины отбрасываются. Ноты, которые начались в первой половине и заканчивались во второй, обрываются в конце нового лупа |
| **Double loop** | Удвоить луп, события дублируются. Не выполняется, если луп станет длиннее 65000 тиков или событий станет больше 5000 |
| **Delete preset** | Выбрать слот и удалить пресет |

Transpose, Half loop и Double loop работают только когда луп играет (PLAY или OVERDUB).

Квантизация работает в двух режимах: **на лету** при записи (если Grid не OFF) и **постфактум** через Apply quantize. Слишком короткие после квантизации ноты автоматически удлиняются до минимальной длины.

Параметры квантизации (Grid, Strength, Target) **не сохраняются** при перезагрузке. Из настроек сохраняется только маска каналов.

### Подменю Channels
Сетка 2×8 с каналами 1–16 и двумя кнопками внизу.

| Элемент | Значение |
|---|---|
| Залитая клетка | канал **записывается** |
| Цифра без заливки | канал **игнорируется** |
| Рамка | текущая позиция курсора |
| `ALL ON` / `ALL OFF` | включить / выключить все каналы |

- **Энкодер** двигает курсор, **клик** переключает канал.
- **Кнопка Menu** — возврат в основной список.
- Настройка **сохраняется** во флеш (`/chmask.bin`) и переживает перезагрузку.
- Фильтр действует только на **запись**. Входящий MIDI принимается со всех каналов, а при воспроизведении события уходят на тех каналах, на которых были записаны.
- **По умолчанию записываются все 16 каналов.** Если маска уже была сохранена ранее, она переопределяет значение по умолчанию (чтобы вернуть все каналы, нажмите `ALL ON`).
- Если выключить канал, пока на нём звучит нота, её Note Off всё равно будет записан, чтобы в лупе не осталось залипшей ноты.

## 6. Индикация нот (низ экрана)

Каждая нота рисуется вертикальной полоской. Положение по горизонтали — высота ноты, высота полоски — velocity (1–6 пикселей).

- **Диапазон:** ноты **24…103** (C1–G7), растянутые на всю ширину экрана. Две нижние и две верхние октавы не показываются.
- **Сплошные полоски** — входящие ноты (с DIN и USB, со всех каналов, независимо от фильтра каналов).
- **Шахматные («серые») полоски** — ноты, которые играет сам лупер.
- Пока нота звучит, полоска держится. После отпускания она плавно гаснет за 350 мс.
- В самой нижней строке «линейка»: точки на каждой ноте До (C1…C7).
- Входящий All Notes Off (CC 123 и CC 120) сбрасывает индикацию входящих нот. Индикация нот лупера сбрасывается при Reset и MIDI Start. Зависшая нота гаснет через 15 с (входящая) или 70 с (нота лупера).

## 7. Что записывается

- **Записываются:** Note On / Note Off и Control Change (с DIN и с USB).
- **Не записываются:** Pitch Bend, Aftertouch, Program Change, SysEx.
- **Режим thru выключен:** входящие события не пересылаются на выход, на выход идёт только воспроизведение лупа.
- **Лимиты:** до 5000 событий (лишние не записываются), длина лупа не более 65000 тиков клока (≈ 677 тактов, то есть около 22 минут при 120 BPM).
- **Нота, нажатая раньше старта записи:** если клавиша зажата в момент старта записи (на первой доле), нота записывается с первой доли, как будто вы попали точно в начало такта. Velocity сохраняется.

## 8. Работа лупера

- **Слои.** Каждый овердаб пишется как новый слой. Undo снимает последний слой. Слой создаётся при каждом входе в овердаб, даже если ничего не сыграно, поэтому Undo после «пустого» овердаба внешне ничего не меняет.
- **Овердаб.** Записанные вживую ноты не «переигрываются» лупером сразу, а начинают звучать со следующего круга. Если выйти из овердаба при зажатой клавише, её Note Off всё равно будет записан. «Сиротские» Note Off (без записанного Note On) не записываются.
- **Защита от эха.** Входящие ноты той же высоты на том же канале в течение 40 мс после того, как лупер сам их отправил, игнорируются. Если в DAW выход лупера заведён обратно на его вход, получится петля. Настройте маршрутизацию так, чтобы выход не возвращался на вход.
- **CC-автоматизация.** Если во время воспроизведения (PLAY) вы сами двигаете CC, записанные значения этого CC на 1,2 с уступают вашему управлению.
- **CC в овердабе — перезапись.** Когда вы двигаете CC в овердабе, старые значения этого CC (тот же канал и номер) **стираются** на том участке лупа, который прошла ручка, и записываются новые. Пауза ручки дольше 1 с завершает участок. Пока овердаб включён, тронутый CC не воспроизводится вообще (ни старый, ни новый), воспроизведение возвращается после выхода из овердаба. **Undo стёртые старые значения не восстанавливает.**
- **Пресеты:** 5 слотов во флеш-памяти (LittleFS, `/presetN.bin`). Загрузка всегда **отложенная**:
  - если луп играет — в **конце текущего круга**;
  - если лупа нет или идёт запись — на **первой доле** ближайшего такта. Загруженный луп стартует с нуля ровно на ней. Идущая запись при этом отбрасывается.
  - Пока загрузка ждёт, на экране `Load N pending...`, а LED «дышит». Кнопка Reset отменяет ожидающую загрузку.
  - Если одновременно ждут и старт/стоп записи, и загрузка, выполняется загрузка.

### MIDI-клок, Start, Continue, Stop

- Все времена в лупе хранятся в тиках клока (24 на долю), поэтому луп следует за изменениями темпа. BPM на экране — скользящее среднее за 2 доли.
- **Start** сбрасывает позицию лупа в начало, состояние лупера не меняется. Если в этот момент идёт **запись**, текущий дубль стирается и запись начинается заново с нулевой позиции. В овердабе слои сохраняются, воспроизведение и запись продолжаются с начала.
- **Continue** позицию не сбрасывает.
- **Stop не обрабатывается.** Если клок пропал больше чем на 1,2 с, включается внутренний клок в **последнем измеренном темпе** (до первого клока после включения — ≈110 BPM), и луп продолжает играть. Остановить воспроизведение можно только кнопкой Reset (с очисткой лупа).

## 9. LED

Пульс плавный, без резких вспышек.

| Состояние | Поведение |
|---|---|
| **IDLE** | Очень мягкий пульс в такт, на первой доле заметнее |
| **PLAY** | Пульс ярче, на первой доле ещё заметнее |
| **REC / OVERDUB** | Светится, на каждой доле плавно проседает (на первой — глубже) |
| **Ожидание** старта, стопа или загрузки пресета | Плавное «дыхание» (~2 Гц) |

## 10. USB MIDI (ESP32-S2 / ESP32-S3)

Включается флагом `USB_MIDI_ENABLED 1`. В Arduino IDE нужно:
- `Tools → USB Mode → USB-OTG (TinyUSB)`;
- `USB CDC On Boot → Enabled` (чтобы работали автопрошивка и Serial);
- подключаться в **нативный USB-порт** платы.

Как это работает:
- **Вход:** принимаются Note On/Off, CC, Clock, Start и Continue.
- **Выход:** воспроизведение идёт одновременно на DIN и на USB.
- **Клок:** если он приходит и с DIN, и с USB, используется тот источник, который активен первым. Второй игнорируется, поэтому «двойных» тиков нет.
- **Устройство** называется `MIDI-Looper` (порт в DAW может отображаться как `TinyUSB MIDI`).
- **Примечания:** после перепрошивки перетыкайте кабель и перезапускайте DAW. При работе с DAW закрывайте Serial Monitor, потому что его открытие может перезагрузить плату. Windows открывает MIDI-порт эксклюзивно, поэтому закрывайте другие программы, которые его держат.

## 11. BLE

Устройство: `MIDI-Looper`. Команды пишутся в характеристику (write), ответы приходят уведомлениями (notify).

| Команда | Действие |
|---|---|
| `/rec`, `/stop` | Старт записи (только из IDLE) и стоп записи (только из REC). Срабатывают на первой доле такта. `/stop` останавливает только запись, не воспроизведение |
| `/overdub`, `/play` | Вход в овердаб (из PLAY) и выход из него (из OVERDUB), сразу |
| `/reset`, `/undo` | Сброс, отмена слоя |
| `/half`, `/double` | Длина лупа ×½ и ×2 |
| `/transpose N` | Транспонировать на N полутонов (без ограничения ±12, в отличие от меню) |
| `/save N`, `/load N`, `/delp N`, `/getpresets` | Пресеты (слот 1–5). `/load` отложенная (см. раздел 8) |
| `/qgrid 0..4`, `/qstrength 0..100`, `/qtarget 0..2` | Параметры квантизации (target: 0 — start, 1 — end, 2 — both) |
| `/getquant`, `/qapply` | Запрос параметров квантизации, применение квантизации |
| `/chmask N` | Маска каналов записи (бит 0 = канал 1 … бит 15 = канал 16), N = 0..65535. Сохраняется во флеш |
| `/getch` | Запросить текущую маску |

Основные уведомления:
- **Состояние:** `/state`, `/pos`, `/rec_pos`, `/beatinfo`.
- **События для визуализации:** `/noteon`, `/noteoff`, `/cc` и их `/rec_*` варианты.
- **Статусы:** `/presets`, `/quant`, `/chmask`, `/load_pending`, `/reset`, `*_ok`, `*_err`.
- Команды `/half`, `/double`, `/transpose` подтверждений не присылают: после `/transpose` луп заново передаётся клиенту целиком.
